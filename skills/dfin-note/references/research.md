# Research Notes

Use `category="research"`. Preserve original analysis, durable conclusions, and expensive-to-recreate supporting work rather than routine lookup output.

## Select Content

- Preserve conclusions, thesis changes, variant views, and causal explanations.
- Preserve decisive facts, assumptions, counterevidence, material uncertainty, risks, open questions, and what would matter next.
- Include summarized or processed analytics when they support the conclusions.
- Include raw or semi-raw data only when it is central to the reasoning or costly to reconstruct. Use compact tables with units, periods, and source identifiers.

## Shape the Body

Write the body in Markdown (using correct markdown syntax) and use the smallest structure that makes the note self-standing. Include only elements supported by material content. Combine, rename, reorder, or omit sections as appropriate; never add an empty or boilerplate section merely to follow this list.

Possible Markdown elements include:

- Optional context lines such as `**Date:**` or `**Scope:**` when they add information not already clear from the note.
- `## Key insights` for decision-relevant conclusions or a variant view.
- `## Analysis` for material reasoning, assumptions, risks, counterevidence, or changed conclusions.
- `## Data compiled` for expensive-to-recreate figures, calculations, or comparisons. Use Markdown tables only when tabular structure improves comprehension.
- `## Relation to existing research` when prior notes or DFin reports materially support, contradict, update, or become stale because of the analysis.
- `## References` for material sources, using Markdown links such as `[Source title](https://example.com)` when a stable URL is available.
- `## Follow-ups` only for genuine open questions, missing evidence, or next diligence steps.

A straightforward note may need only a concise conclusion, supporting evidence, and references. Use headings when they improve navigation; short notes may use ordinary Markdown paragraphs and bullets without section headings.
